##branches

<!--to check all availble branches-->
git branch  <br>

<!--to rename the existing branch-->
git branch -M <your branch name> <br>

<!-- to create a new branch-->
git checkout -b <new branch name> <br>

<!-- to delete a branch-->
git checkout -d <branch name> <br>

<!-- to switch a branch-->
git checkout <branch name> <br>


<!-- to pull the changes from one brnach to another branch -->
git pull origin <branch name you want to pull> <br>

<!--merging one branch with another-->
git merge <branch name> <br>
